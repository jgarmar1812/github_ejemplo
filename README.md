# github_ejemplo
Lo mismo que hemos hecho en local, ahora desde servidor externo.

## Pasos para sincronizar con Internet
0. **Pull**. No sabemos si alguien ha hecho cambios en los archivos de internet. Deberíamos descargalos.
0. En cuanto escribimos algo que esta sin grabar, en la pestaña de este archivo sale un punto gordo, para avisarnos.
1. Grabar los cambios (Ctrl+S) - Aparece una marca en el icono de *source control* con el numero de archivos en los que hemos guardado cambios.
2.  **Stage**: Marcar los archivos cambiados para que se preparen para ser "controlados" por el sistema.
3.  **Commit**: Añadir los archivos marcados a uno nuevo punto de control de versiones.
4.  **Push**: sincronizar (subir) lo que tenemos en ordenador

 ## Errores posibles:

 1. **No hacer stage**. Si no le dais al `+`, no hay nada que confirmar te sugiere añadir él mismo los cambios.
 2.  **No poner el mensaje de commit**. El programa te abre una pestaña para que lo ponga. Hay que escribirlo, guardar y cerrar esa pestaña.
 3.   **Olvidar sincronizacion**. Esto no puedo sartarmelo.
